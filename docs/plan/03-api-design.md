# 03 — API design

Base path `/api/v1`. JSON only. OpenAPI generated by `dedoc/scramble` from form requests, API resources, and controllers. The TypeScript client in `frontend/packages/api-client` is generated in CI. A drift check fails the build if the spec changed and the client was not regenerated.

Module behaviour sits in [04-module-breakdown.md](./04-module-breakdown.md). Tables sit in [02-domain-and-database.md](./02-domain-and-database.md).

## 1. Conventions

### Envelope

Success:

```json
{ "data": {}, "meta": { "request_id": "uuid" }, "error": null }
```

List:

```json
{
  "data": [],
  "meta": { "request_id": "uuid", "next_cursor": null, "prev_cursor": null, "per_page": 25 },
  "error": null
}
```

Error:

```json
{
  "data": null,
  "error": {
    "code": "entitlement.limit_exceeded",
    "message": "Product limit reached for this plan.",
    "details": { "feature": "limit.products", "limit": 100 },
    "request_id": "uuid"
  }
}
```

| HTTP | `error.code` prefix | When |
| --- | --- | --- |
| 401 | `auth.` | Missing or bad session |
| 403 | `permission.` or `entitlement.` | Role or plan |
| 404 | `resource.` | Missing, or hidden by RLS (do not reveal which) |
| 409 | `conflict.` | State machine, unique slug |
| 422 | `validation.` | Form request. `details` is the field map |
| 429 | `rate_limit.` | Include `Retry-After` |
| 402 | `billing.` | Subscription suspended. Staff can still sign in to billing routes |

Validation messages are a stable code plus a human English string. The client may translate later. Do not make the English string the only contract.

### Pagination, filter, sort

- Cursor pagination via `spatie/laravel-query-builder` on an indexed column (`created_at`, `id`) encoded as an opaque cursor.
- `per_page` default 25, max 100.
- `filter[status]=active`, `filter[created_at]=2026-10-01,2026-10-19`, `sort=-created_at`.
- Allow-list every filter. Unknown filters return 422.
- No offset parameters on sales, orders, ledgers, or audit.

### Idempotency

Header `Idempotency-Key` required on:

- `POST` sales, sale sync, checkout, payment create, refund, tenant create, catalog import commit, order transition.

Same key + same body hash returns the stored response. Same key + different hash returns `409 conflict.idempotency_key`. Keys live 7 days in `idempotency_keys`.

`sales.client_uuid` duplicates this for the offline path so a retry without the header still dedupes. Send both; they must match.

### Tenant resolution

The host is the authority. Body `tenant_id` is ignored.

| Host | Context |
| --- | --- |
| `admin.{APP_DOMAIN}` | Platform. No tenant scope unless a route contains `{tenant}` |
| `{slug}.{APP_DOMAIN}` | That tenant. `store_id` comes from the path |
| `{publicSlug}.shop.{APP_DOMAIN}` | That store, or the org storefront |

A path `store_id` that is not in the resolved tenant returns 404.

### Rate limits (Redis)

| Key | Limit |
| --- | --- |
| Login IP | 5 / minute |
| Login account | 10 failures / hour then lock |
| OTP phone | 1 / 30 s, 5 / hour, 20 / day |
| OTP IP | 50 / hour |
| Staff writes | 120 / minute / user |
| Catalog search | 60 / minute / user |
| API key | 60 / minute default, overridable down |
| Webhook ingress IP | 300 / minute |
| AI routes | plan credits plus 20 / minute / user |

### Auth headers

Web: session cookie + `X-XSRF-TOKEN`. Native later: `Authorization: Bearer`. API keys: `Authorization: Bearer sk_live_...` only on `/api/v1/open/*`.

### Resources

- Dates ISO-8601 UTC.
- Money as integers in paise plus a display hint is not required; the client formats INR with `en-IN`.
- Ids are uuid strings.

| Method | Path |
| --- | --- |
| GET POST | `/api/v1/platform/gateways` |

Webhook route has no session. Verification is the provider signature. The raw body is stored on `webhook_receipts` only after the signature check. Duplicate `provider_event_id` returns 200 with the original result.

Drivers in Phase 1: `razorpay`, `cashfree`, `phonepe`, `paytm`, `cod`, `pay_at_store`, `manual`. `GET /platform/gateways/drivers` lists the registry and the credential form schema for each. A tenant only sees drivers Super Admin has marked available. Enabling a prepaid driver requires verify to succeed. Checkout calls `PaymentDriver`, never a vendor SDK.

Adapter methods each provider class must implement: `createPayment`, `fetchStatus`, `refund`, `verifyWebhook`, `parseEvent`. Drivers: `RazorpayGateway`, `CashfreeGateway`, `PhonePeGateway`, `PaytmGateway`, `CodGateway`, `PayAtStoreGateway`, `ManualGateway`.

## 21. Outbound webhooks

Tenant endpoints subscribe to a subset of the catalogue. Delivery body:

```json
{
  "id": "outbox uuid",
  "type": "order.status.changed",
  "sequence": 120044,
  "created_at": "2026-10-19T10:00:00Z",
  "data": {}
}
```

Headers: `X-Selfx-Signature: t=timestamp,v1=hmac_sha256(secret, timestamp.body)`. Receivers should reject timestamps older than 5 minutes. Retries: 5, backoff 1m, 5m, 15m, 1h, 6h. The signing secret is shown once at create and stored as `webhook_endpoints.secret_ciphertext` (the server must be able to sign later). API keys are different: only `secret_hash` is stored, because those are verified, not reused to sign.
